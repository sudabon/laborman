# Spec Delta

## Purpose

勤務日ごとの休憩（開始・終了）を記録し、タスクとの切り替えや既定の休憩の登録を簡単に行えるようにするための機能。

## ADDED Requirements

### Requirement: 休憩の記録

システムは、勤務日ごとに休憩（開始時刻・終了時刻・登録元）を複数件記録し、追加・編集・削除できなければならない（SHALL）。終了時刻のない休憩は進行中として扱い、同一勤務日に進行中の休憩は最大 1 件でなければならない（MUST）。休憩にも、タスクと同じ時間帯の重なりの拒否と勤務日基準の時刻入力を適用しなければならない（MUST）。手入力の休憩の登録元は `manual` とする。

#### Scenario: 過去日に休憩を追加する

- **WHEN** ユーザーが 2026-10-09 に 12:00–13:00 の休憩を入力して保存する
- **THEN** システムは登録元 `manual` の休憩として保存し、業務明細の一覧に「(休憩)」として表示する

#### Scenario: 休憩がタスクと重なる

- **WHEN** 11:00–12:30 のタスクがある日に 12:00–13:00 の休憩を保存しようとする
- **THEN** システムは `409` を返し、重なっているタスクの ID と時間帯を示す

### Requirement: 休憩開始

システムは「休憩開始」操作で、進行中タスクを現在時刻で終了させ、現在時刻を開始時刻とする進行中の休憩を作成しなければならない（SHALL）。

#### Scenario: 作業中に休憩を開始する

- **WHEN** 09:00 開始の JOB-A のタスクが進行中で、12:00 に「休憩開始」する
- **THEN** システムは JOB-A を 12:00 で終了し、12:00 開始の進行中の休憩を作成する

### Requirement: 休憩終了とタスク再開

システムは「休憩終了」操作で、進行中の休憩を現在時刻で終了させなければならない（SHALL）。休憩終了後、システムは直前に終了したタスクと同じジョブ・内容でタスクを開始する「再開」操作を提示しなければならない（SHALL）。

#### Scenario: 休憩を終えて作業を再開する

- **WHEN** 12:00 開始の休憩が進行中で、ユーザーが 13:00 に「休憩終了」し、続けて「再開」する
- **THEN** システムは休憩を 13:00 で終了し、休憩前に終了した JOB-A・同じ内容のタスクを 13:00 開始の進行中タスクとして作成する

### Requirement: 既定の休憩

システムは、設定で既定の休憩の開始・終了時刻（初期値 12:00–13:00）を保存・編集できなければならない（SHALL）。「本日の報告」画面では「既定の休憩を追加」操作で、表示中の勤務日に既定の休憩を登録元 `manual` として追加できなければならない（SHALL）。既定の休憩は利用者の操作なしに自動で保存してはならない（MUST NOT）。

#### Scenario: 既定の休憩を追加する

- **WHEN** 既定の休憩が 12:00–13:00 の設定で、ユーザーが 2026-10-09 に「既定の休憩を追加」する
- **THEN** システムは 2026-10-09 に 12:00–13:00 の休憩を追加する

#### Scenario: 既定の休憩を変更する

- **WHEN** ユーザーが設定画面で既定の休憩を 11:45–12:45 に変更して保存する
- **THEN** システムは以降の「既定の休憩を追加」で 11:45–12:45 を使う
