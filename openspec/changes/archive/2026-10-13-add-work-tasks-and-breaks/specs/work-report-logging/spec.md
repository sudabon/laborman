# Spec Delta

## MODIFIED Requirements

### Requirement: 終業記録と勤務時間計算

システムは、ユーザーが当日の終業を記録できる手段を提供しなければならない（SHALL）。記録時、システムは現在日時を終業時刻として保存し、当日の始業時刻が存在する場合は勤務時間を算出できなければならない（MUST）。終業の記録時に進行中のタスクまたは休憩がある場合、システムは「進行中のタスクを終業時刻で終了しますか？」と確認し、利用者が承認した場合にのみ終業時刻で終了させなければならない（MUST）。

#### Scenario: 始業記録済みの日に終業を記録する

- **WHEN** 当日の `start_time` が記録済みの状態でユーザーが終業を記録する
- **THEN** システムは `end_time` に現在日時を保存し、`end_time - start_time` から勤務時間を算出し、ステータスを `end_recorded` にする

#### Scenario: 始業記録がない日に終業を記録する

- **WHEN** 当日の `start_time` が未記録の状態でユーザーが終業を記録する
- **THEN** システムは終業時刻を保存しつつ、勤務時間を未計算（不明）として扱い、ユーザーに始業未記録である旨を示す

#### Scenario: 進行中のタスクがある状態で終業を記録する

- **WHEN** 進行中のタスクがある状態でユーザーが終業を記録し、確認で終了を承認する
- **THEN** システムは進行中のタスクを終業時刻で終了させ、終業時刻を保存する

#### Scenario: 進行中のタスクの終了を承認しない

- **WHEN** 進行中のタスクがある状態でユーザーが終業を記録し、確認で取り消す
- **THEN** システムは終業時刻を保存せず、進行中のタスクも変更しない

### Requirement: 保存情報の範囲

システムは、勤務日・始業時刻・終業時刻・勤務区分・メモ・メール作成日時・終業メール本文（ヘッダ/フッタを除く）・タスク（ジョブ ID・内容・開始・終了）・休憩（開始・終了・登録元）・ジョブマスタ・既定の休憩のみを保存対象とし、始業メール本文、終業メールのヘッダ/フッタ（テンプレートとして `mail_settings` 側に保持）、ならびに Microsoft 365 のパスワード、Outlook 認証情報、Graph アクセストークン、SMTP/アプリパスワードを保存してはならない（MUST NOT）。

#### Scenario: 記録保存時に認証情報を含めない

- **WHEN** ユーザーの始業・終業、タスク、休憩が記録される
- **THEN** 保存されるレコードには勤務日・時刻・勤務区分・メモ・メール作成日時・終業メール本文（ヘッダ/フッタ除く）・タスク・休憩のみが含まれ、いかなる外部メール認証情報も含まれない

#### Scenario: 始業メール本文は保存しない

- **WHEN** 始業メールが作成される
- **THEN** システムは始業メール本文を永続化せず、始業メール作成日時（`start_mail_created_at`）のみを記録する
