# Spec Delta

## ADDED Requirements

### Requirement: 出退勤に合わせたタスクの時刻合わせ

システムは、勤務の出退勤実績（出勤・退勤の両方）を登録・更新したとき、その日の最初のタスクの開始時刻を出勤時刻に、最後のタスクの終了時刻を退勤時刻に合わせなければならない（SHALL）。登録元（人事メール・手入力）は問わない。ずれが 30 分を超える場合は記録漏れの可能性があるため変更してはならず（MUST NOT）、ドラフトの検証結果で知らせる。次の場合も変更してはならない（MUST NOT）：zac 登録済みの日、最初のタスクより前（最後のタスクより後）に休憩がある場合のその端、進行中のタスクがある日の終了時刻、変更するとタスクの開始が終了以降になる場合。

#### Scenario: わずかなずれを合わせる

- **WHEN** タスクが 08:15–12:00 と 13:00–20:20 の日に、人事メールから出退勤 08:14–20:23 を取り込む
- **THEN** システムはタスクを 08:14–12:00 と 13:00–20:23 に変更する

#### Scenario: はみ出したタスクを縮める

- **WHEN** タスクが 08:00–12:00 と 13:00–18:45 の日に、出退勤 08:10–18:30 を手入力する
- **THEN** システムはタスクを 08:10–12:00 と 13:00–18:30 に変更する

#### Scenario: 大きなずれは合わせない

- **WHEN** タスクが 09:00–17:00 だけの日に、出退勤 08:14–17:31 を取り込む
- **THEN** システムはタスクを変更せず、ドラフトの検証結果で空き時間を知らせる
