# Spec Delta

## MODIFIED Requirements

### Requirement: タスクの記録

システムは、勤務日ごとにタスク（ジョブ ID・作業内容・売上項目・内容・開始時刻・終了時刻）を複数件記録できなければならない（SHALL）。終了時刻のないタスクは進行中として扱う。内容は 200 文字以内でなければならず（MUST）、超える場合は保存を拒否する。売上項目はタスクのジョブの売上項目でなければならず（MUST）、違う場合は `422` を返す。作業内容と売上項目は未設定でも保存できるが、zac 登録のドラフトでは error とする。タスク一覧は開始時刻の昇順で返さなければならない（SHALL）。

#### Scenario: 勤務日のタスク一覧を取得する

- **WHEN** ユーザーが 2026-10-09 のタスク一覧を要求する
- **THEN** システムは当日のタスクを開始時刻の昇順で返し、各タスクのジョブ ID・作業内容・売上項目・内容・開始・終了（進行中は空）を含める

#### Scenario: 内容が長すぎる

- **WHEN** ユーザーが 201 文字の内容でタスクを保存しようとする
- **THEN** システムは `422` を返し、タスクを保存しない

#### Scenario: 別のジョブの売上項目

- **WHEN** ジョブ 2601570 のタスクに、ジョブ 2602028 の売上項目を指定して保存しようとする
- **THEN** システムは `422` を返し、タスクを保存しない

### Requirement: 時刻を指定したタスクの追加

「本日の報告」画面の業務明細は、ジョブ・売上項目・作業内容・内容・開始時刻・終了時刻を入力して「追加」する操作でタスクを登録しなければならない（SHALL）。時刻は勤務日基準の `HH:MM`（時分のみ。`24:00`〜`29:59` は翌日）で入力し、秒を持たない時刻として保存しなければならない（MUST）。終了時刻を空欄にした場合は進行中のタスクとして保存する。ジョブを選ぶと、システムは売上項目と作業内容に初期値を入れなければならない（SHALL）。売上項目の初期値は、勤務日の年月を対象年月とする項目、なければそのジョブで前回使った項目、なければ選択肢が 1 つならその項目とし、どれにも当たらなければ空にする。売上計上済みの項目は初期値にしてはならない（MUST NOT）。作業内容の初期値は、そのジョブで前回使った作業内容、なければジョブの既定の作業内容とする。追加に成功したら、内容を空にし、次の開始時刻に今回の終了時刻を入れなければならない（SHALL）。画面には「タスク開始」「停止」「再開」の操作を表示してはならない（MUST NOT）。

#### Scenario: 時刻を入力してタスクを追加する

- **WHEN** ユーザーが 2026-10-09 に 2602028・「設計レビュー」・開始 09:00・終了 10:30 を入力して「追加」する
- **THEN** システムは売上項目「プロジェクトサポート（2026／10）」と前回の作業内容を初期値として、09:00:00–10:30:00 のタスクを保存し、入力欄の開始を 10:30、内容を空にする

#### Scenario: 作業の種類を表す売上項目を選ぶ

- **WHEN** ユーザーが 2600901 を選び、売上項目「外部研修」を選んでタスクを追加する
- **THEN** システムは売上項目「外部研修」でタスクを保存し、次に 2600901 を選んだときは「外部研修」を初期値にする

#### Scenario: 時刻の形式が不正

- **WHEN** ユーザーが開始に `9時` を入力して「追加」する
- **THEN** システムは API を呼ばずに `HH:MM` 形式で入力するよう表示する
