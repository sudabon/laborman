# Spec Delta

## MODIFIED Requirements

### Requirement: 本日の報告画面

システムは、当日の始業・終業報告を行う「本日の報告」画面を提供しなければならない（SHALL）。当日の始業時刻・終業時刻・勤務時間・メモを表示し、記録操作の起点とする。画面には業務明細として、ジョブ選択・内容入力と「タスク開始」「休憩開始」「停止」「休憩終了」「再開」「既定の休憩を追加」「行を追加」の操作、タスクと休憩を開始時刻順に並べた一覧（開始・終了・ジョブ・内容・時間、編集・削除）、作業と休憩の合計時間を表示しなければならない（SHALL）。進行中のタスク・休憩は終了時刻の代わりに進行中であることを示さなければならない（SHALL）。自由記述の「業務報告」入力欄は表示してはならず（MUST NOT）、代わりにメール作成の領域に `{{tasks}}` の展開結果を読み取り専用・コピー可能なプレビューとして表示しなければならない（SHALL）。カレンダーから過去日を開いた場合も、同じ画面でその日の業務明細を編集できなければならない（SHALL）。画面には打刻（laborman）とは別に出退勤（人事メール）の出勤・退勤時刻・登録元・取込日時を表示し、未登録の場合は「未取込」、区分が休暇の場合は「休暇」と表示しなければならない（SHALL）。出退勤の「手入力」操作から出勤・退勤・区分を入力・上書きできなければならない（SHALL）。

#### Scenario: 本日の報告画面を表示する

- **WHEN** ユーザーが本日の報告画面を開く
- **THEN** システムは当日の日付、始業報告/終業報告の操作、記録済みの始業時刻・終業時刻・勤務時間・メモ、業務明細の操作と一覧、作業・休憩の合計時間を表示する

#### Scenario: カレンダーから本日の報告へ遷移する

- **WHEN** ユーザーがカレンダー上で本日の報告操作を選ぶ
- **THEN** システムは本日の報告画面を表示し、その場で始業・終業を記録できる

#### Scenario: 過去日の業務明細を編集する

- **WHEN** ユーザーがカレンダーで 2026-10-09 を選ぶ
- **THEN** システムは 2026-10-09 のタスクと休憩を一覧表示し、行の追加・編集・削除を受け付ける

#### Scenario: 重なりエラーを表示する

- **WHEN** ユーザーが既存のタスクと重なる行を保存しようとする
- **THEN** システムは保存されなかったことと、重なっている相手の時間帯を画面に表示する

#### Scenario: 業務報告欄の代わりにプレビューを表示する

- **WHEN** ユーザーが本日の報告画面でメール作成の領域を見る
- **THEN** システムは自由記述の「業務報告」入力欄を表示せず、当日のタスクから生成した `{{tasks}}` のプレビューとコピー操作を表示する

#### Scenario: 出退勤が未取込の日

- **WHEN** ユーザーが当日の報告画面を開き、出退勤実績がまだ登録されていない
- **THEN** システムは出退勤（人事メール）を「未取込」と表示し、打刻（laborman）の時刻は別の行に表示する

#### Scenario: 出退勤を手入力する

- **WHEN** ユーザーが出退勤の「手入力」から出勤 09:00・退勤 18:30 を入力して保存する
- **THEN** システムは出退勤実績を登録元 `manual` で保存し、画面に 09:00 – 18:30 と手入力であることを表示する
