# Spec Delta

## MODIFIED Requirements

### Requirement: 保存情報の範囲

システムは、勤務日・始業時刻・終業時刻・勤務区分・メモ・メール作成日時・終業メール本文（ヘッダ/フッタを除く）・タスク（ジョブ ID・内容・開始・終了）・休憩（開始・終了・登録元）・ジョブマスタ・既定の休憩・出退勤実績（出勤・退勤・登録元・区分・取込日時・休憩分数）・人事メールの検索条件のみを保存対象とし、始業メール本文、終業メールのヘッダ/フッタ（テンプレートとして `mail_settings` 側に保持）、人事メールの本文、ならびに Microsoft 365 のパスワード、Outlook 認証情報、Graph アクセストークン、SMTP/アプリパスワードを保存してはならない（MUST NOT）。

#### Scenario: 記録保存時に認証情報を含めない

- **WHEN** ユーザーの始業・終業、タスク、休憩が記録される
- **THEN** 保存されるレコードには勤務日・時刻・勤務区分・メモ・メール作成日時・終業メール本文（ヘッダ/フッタ除く）・タスク・休憩のみが含まれ、いかなる外部メール認証情報も含まれない

#### Scenario: 始業メール本文は保存しない

- **WHEN** 始業メールが作成される
- **THEN** システムは始業メール本文を永続化せず、始業メール作成日時（`start_mail_created_at`）のみを記録する

#### Scenario: 人事メールの本文は保存しない

- **WHEN** エージェントが人事メールから出退勤実績を取り込む
- **THEN** システムは抽出した時刻・区分・休憩のみを保存し、人事メールの本文・件名・差出人の実データを DB に保存しない
