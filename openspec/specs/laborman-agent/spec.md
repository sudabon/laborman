# laborman-agent Specification

## Purpose
VPN や社内サインインが必要な外部画面（Outlook on the web・zac）の自動操作を、利用者の Mac 上で安全に実行するためのホスト側 CLI の共通動作を定める。

## Requirements

### Requirement: API 経由のデータアクセス

エージェントは、laborman のデータを HTTP API 経由でのみ読み書きしなければならず（MUST）、データベースに直接接続してはならない（MUST NOT）。API の接続先は設定ファイルで指定する（既定 `http://127.0.0.1:8888`）。

#### Scenario: API に接続できない

- **WHEN** laborman が起動していない状態でエージェントのコマンドを実行する
- **THEN** エージェントは API に接続できない旨を出力し、終了コード `1` で終了する

### Requirement: 終了コード

エージェントのコマンドは、完了またはスキップで `0`、想定外のエラーで `1`、後で再試行すべき状態（メール未着・VPN 未接続など）で `2`、人の対応が必要な状態（サインイン切れ・検証エラー・解析失敗など）で `3` を返さなければならない（SHALL）。

#### Scenario: サインイン切れ

- **WHEN** `fetch-attendance` の実行中に Outlook on the web のサインイン画面が表示される
- **THEN** エージェントはサインインが必要である旨を通知し、終了コード `3` で終了する

### Requirement: 対象日の決定

エージェントは、対象日を既定で実行日の前営業日（土日と日本の祝日を除く）としなければならず（SHALL）、`--date YYYY-MM-DD` で指定できなければならない（SHALL）。

#### Scenario: 月曜に実行する

- **WHEN** 2026-10-12（月）に対象日を指定せずに実行する
- **THEN** エージェントは 2026-10-09（金）を対象日とする

#### Scenario: 祝日明けに実行する

- **WHEN** 祝日の翌営業日に対象日を指定せずに実行する
- **THEN** エージェントは祝日と土日を飛ばした直前の営業日を対象日とする

### Requirement: 多重起動の防止

エージェントは、同時に 2 つ以上の実行が走らないよう排他しなければならない（MUST）。すでに実行中の場合、後から起動した実行は何もせずに終了コード `0` で終了しなければならない（SHALL）。

#### Scenario: 実行中に再度起動する

- **WHEN** エージェントの実行中に、もう 1 つの実行を起動する
- **THEN** 後から起動した実行は処理を行わず、実行中である旨を出力して終了コード `0` で終了する

### Requirement: 手動サインイン

エージェントは、`laborman-agent login owa` で画面付きブラウザを開き、利用者が手動でサインインしたセッションを専用のブラウザプロファイルに保存できなければならない（SHALL）。エージェントはパスワードを入力・保存してはならない（MUST NOT）。プロファイルのディレクトリは所有者のみアクセス可能な権限（`700`）で作成しなければならない（MUST）。

#### Scenario: OWA にサインインする

- **WHEN** 利用者が `laborman-agent login owa` を実行し、開いたブラウザで会社の Microsoft 365 にサインインして閉じる
- **THEN** エージェントはセッションをプロファイルに保存し、以降の `fetch-attendance` は画面なしで OWA を開ける

### Requirement: 診断

エージェントは、`laborman-agent doctor` で API への到達性、設定ファイルの有無と権限、ブラウザプロファイル、ブラウザ自動化に必要なブラウザの導入状況を確認し、項目ごとの結果を表示しなければならない（SHALL）。1 つでも失敗があれば終了コード `3` で終了しなければならない（SHALL）。

#### Scenario: すべて正常

- **WHEN** laborman が起動し、設定・プロファイル・ブラウザが揃った状態で `doctor` を実行する
- **THEN** エージェントは全項目を正常と表示し、終了コード `0` で終了する

### Requirement: 通知

エージェントは、人の対応が必要な結果（終了コード `3`）と警告を macOS の通知で知らせなければならない（SHALL）。通知にメール本文や業務内容の詳細を含めてはならない（MUST NOT）。

#### Scenario: 解析失敗を通知する

- **WHEN** 人事メールの解析に失敗する
- **THEN** エージェントは対象日と「人事メールを解析できませんでした」を macOS 通知で表示し、本文は含めない

### Requirement: 設定ファイルと秘密情報

エージェントは、設定を `~/.config/laborman-agent/config.toml` から読み込まなければならない（SHALL）。画面のセレクタと本文の解析規則は既定値をコードに持ち、設定ファイルで上書きできなければならない（SHALL）。設定ファイルの権限が所有者以外に読み取り可能な場合は警告しなければならない（SHALL）。パスワード・アクセストークンを設定ファイルおよび laborman の DB に保存してはならない（MUST NOT）。

#### Scenario: 設定ファイルの権限が緩い

- **WHEN** 設定ファイルの権限が `644` の状態でコマンドを実行する
- **THEN** エージェントは権限を `600` にするよう警告する
